# ur-network-farm

Mirror / copy of the original from https://git.reformboss.com/reform/ur-network-farm

Free-tier residential egress from URnetwork (ur.io) over the public API.

Original published from the @AlStack channel: https://t.me/AlStack

## Quick start

```bash
python urnet.py farm --count 1 --proxies 1
python urnet.py collect --bank bank.jsonl --out pool.jsonl
python urnet.py balance --bank bank.jsonl
```
